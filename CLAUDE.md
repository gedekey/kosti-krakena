# Кости Кракена — инструкции для Claude

Игра в кости Перудо с механикой жульничества и Безумия, пиксель-арт, лавкрафтовская пиратская таверна.
Godot 4 (GDScript), сначала Windows, потом Android.

## Обязательно прочитать в начале каждого чата
- `DESIGN.md` — геймдизайн, источник истины.
- `ROADMAP.md` — разбивка на модули. Работаем **только над модулем, названным в стартовой фразе**.
- `ART_PROMPTS.md` — когда задача касается арта или звука.

## Правила работы
- Общение с автором — на русском.
- Один чат — один модуль. Чужие модули не трогаем. Если без правки в другом модуле не обойтись, делаем минимальное изменение и говорим об этом.
- Геймдизайн не меняем молча. Если нужно отступить от `DESIGN.md`, спрашиваем автора, а после согласия обновляем `DESIGN.md` (раздел «Журнал изменений»).
- Логика (`core/`, `match/`, `cheats/`, `madness/`, `ai/`) — без зависимостей от нод и UI, RNG только через инъекцию. Покрывается тестами GUT.
- UI только подписывается на события (`Events`) и отправляет команды. Правила в UI не дублируются.
- Числа баланса (риски, шансы, Рассудок) — именованные константы в одном месте, не магические числа.
- Все строки интерфейса — через ключи локализации (RU + EN), без захардкоженного текста.
- Пиксель-арт: внутреннее разрешение 640×360, nearest-фильтр, никаких дробных масштабов.
- Код и имена — на английском, комментарии можно на русском.
- `Изображения/` — только референсы стиля. В игру их не импортируем.

## Конец модуля
1. Тесты зелёные (если модуль их предполагает).
2. Статус модуля в таблице `ROADMAP.md` → ✅. Если что-то перенесено, это записано в раздел модуля.
3. Коммит на русском с префиксом `[М<N>]`.
